导入链路：DocumentImportService.importFile（.txt → 解析/清洗/切分）→ MySQL knowledge_document/document_page_content 台账 →
DocumentVectorIndexService.indexDocument(STRUCTURE) → Embedding（local-hashing-embedding，384 维）→ PG vector_store（pgvector，cosine <=>，HNSW）。
