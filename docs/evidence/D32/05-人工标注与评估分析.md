## 三、噪声/漏召回原因分析

1. **同文档聚合挤占**（漏召回主因）：C01/C02 同主题片段得分接近，Top-K 只保留一个名额时相邻片段被挤出。工程对策：结果按 documentId 去重（MMR/分组多样性），或扩大 K 后按文档聚合。
2. **跨设备同现象噪声**（噪声主因）：油温/高温/过热类问题在液压机、空压机、变频器间互相串扰（Q3 rank2、Q5 rank3-4）。local-hashing Embedding 基于字符 n-gram 特征，无法区分设备语义边界；换语义模型（bge/m3e 等 384 维）可显著改善。
3. **教学片段噪声**：提示注入教学片段被 Q8/Q10 召回（仅共享"工单"字样）。该片段本身用于验证"检索系统只展示不执行"，其出现说明过滤仍靠上层（引用展示层）治理，向量层无法识别用途。
4. **分数分布与阈值**：R 分数区间 [0.1707, 0.4508]，N 区间 [0.0796, 0.1976]，P 区间 [0.1710, 0.2546]。**R 与 N 区间重叠（0.17~0.1976）**：设 0.20 阈值可滤全部 N，但会漏掉 Q7 的 rank1 正确答案（0.1707）；设 0.17 保全部 R 但噪声滤除有限。**结论：本语料 + local-hashing 模型上不存在能同时保召回与去噪的阈值，维持暂不设阈值（similarityThreshold=0.0）的决策；阈值建议待更换语义 Embedding 后基于新的分数分布重新评估，若业务必须硬过滤，建议 0.15 起步并配合 Top-K 截断使用。**
